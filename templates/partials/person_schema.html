{#- ProfilePage wrapping the Person entity, emitted on the homepage only. Values come from [extra.person] and [extra] in config.toml. Why the ProfilePage wrapper: Google's Rich Results Test only reports types that are eligible for a rich result. A bare Person is not one of them, so valid Person markup reports "No items detected" there (validator.schema.org accepts it either way). ProfilePage is a supported type, and the homepage is an About-Me page -- a bio focused on a single person affiliated with the site -- which is the case Google scopes ProfilePage to. `sameAs` stays on the Person, which keeps its stable `#person` @id: that is the part that matters, telling search engines this site and the external profiles (Scholar, dblp, GitHub, ...) are one entity. -#} {%- set person = config.extra.person -%} {#- Normalise to exactly one trailing slash so @id/url match rel=canonical. -#} {%- set site_root = get_url(path="/") | trim_end(pat="/") -%} {%- set site_url = site_root ~ "/" -%}
